## Сжатие — что осталось

Сделано по плану владельца (два режима, «было / стало», оригинал в Корзину, освободится X на кнопке).
Устройство — `compcore.py`, `compress_page.py`; программы — `tools/fetch_tools.py` → `third_party\`.

- **Пороги «без видимых потерь» подобрать на настоящих снимках и видео владельца** (папку назовёт владелец).
  Сейчас: фото — качество 85, потом 90, SSIM яркости ≥ 0,985 и худший 1 % блоков ≥ 0,90; видео — SVT-AV1
  CRF 28, preset 8, средний SSIM ≥ 0,97. На синтетике SSIM строг к пропаже мелкого зерна (шум σ = 6:
  0,89 при качестве 85), а на сильном шуме — мягок; возможно, нужен другой счётчик (SSIMULACRA2/Butteraugli).
- **Сборка FFmpeg закреплена по дате** (`autobuild-2026-10-05-13-07` у BtbN): старые сборки там удаляют
  примерно через месяц — тогда CI не скачает её. Выход: положить zip в свой релиз Duplio (`deps`) и качать оттуда.
- Видео на видеокарте (`av1_nvenc` / `av1_qsv` / `av1_amf`) — в разы быстрее, если есть; сейчас только процессор.
- HEIC/HEIF и другие форматы фото, HDR-видео (сейчас пропускаются).
- Продолжить подготовку с места остановки (сейчас «Подготовить» начинает заново).
- Собранную программу запустить на чистой Windows без VC++ Redistributable: `jpegtran` и `oxipng` берут
  `VCRUNTIME140.dll` из `_internal` (через PATH при запуске) — проверено только на машине разработки.
