## Метаданные — что осталось

- Проверить на телефоне и в Google Фото, что после очистки HDR-снимки светятся, а «живые фото» двигаются
  (по разбору файлов всё на месте, но глазами на телефоне не смотрели).
- Видео с телефона владельца (в папке ноября 2024 видео нет) — посмотреть, какие поля пишет Samsung, и
  проверить очистку.
- Запись Samsung с картой глубины или видео внутри (6 снимков владельца) — сейчас не трогается; разобраться,
  можно ли пересобрать её безопасно (Samsung Галерея ищет вложения по её каталогу, Google — по XMP от конца файла).
- Дорожки GPS внутри видео (GoPro `gpmd`, `camm`) — показываются «не убрать»; убрать — только перепаковкой.
- Форматы: MKV/WebM (ffmpeg-перепаковка), HEIC/HEIF, AVIF, WebP, TIFF, RAW — вместе с «Больше форматов».
- Чтение — файл целиком (у фото): на SSD 223 снимка — 15 с в первый раз, 0,6 с из кэша; на HDD может быть
  долго — читать только начало и хвост.

## Сжатие — что осталось

Сделано по плану владельца (два режима, «было / стало», оригинал в Корзину, освободится X на кнопке).
Устройство — `compcore.py`, `compress_page.py`; программы — `tools/fetch_tools.py` → `third_party\`.

- **Фото откалиброваны** (6.10.2026, 223 снимка владельца за ноябрь 2024, из них 107 — Galaxy S24 Ultra
  с качеством 96–97): качество 85, потом 90; SSIM на кадре, уменьшенном вдвое, ≥ 0,985, худший 1 % блоков
  ≥ 0,96, на полном размере худший 1 % ≥ 0,80. Итог на папке: −43 % (150 из 351 МБ), строго без потерь — −4 % (без HDR-карт, которые раньше выбрасывались).
  На полном размере SSIM отклонял 89 из 107 снимков за пропажу шумового зерна, хотя при 150 % разница еле
  видна. 37 снимков Ultra HDR (карта яркости в MPF) пропускаются — её бы потерять.
- **Пороги видео подобрать на настоящих роликах владельца** (в папке ноября 2024 видео нет). Сейчас SVT-AV1
  CRF 28, preset 8, средний SSIM ≥ 0,97; есть фильтр libvmaf — проверить VMAF ≥ 95.
- SSIM почти не видит блоки на гладком градиенте (синтетика с качеством 40 — 0,998): защита — сама лестница
  качества (не ниже 85 и только для снимков с качеством выше); возможно, позже — SSIMULACRA2/Butteraugli.
- Видео на видеокарте (`av1_nvenc` / `av1_qsv` / `av1_amf`) — в разы быстрее, если есть; сейчас только процессор.
- **Больше форматов** (просьба владельца): HEIC/HEIF, AVIF, WebP, TIFF, RAW (DNG и др.) — фото; MOV/MP4
  с HEVC, AVI, MTS/M2TS, 3GP, WMV — видео; HDR-видео (сейчас пропускается).
- **Конвертация** (просьба владельца, потом): например, HEIC → JPEG, старые AVI/WMV → MP4, по желанию —
  AVIF для фото; с тем же сравнением «было / стало» и переносом метаданных и дат.
- **Ultra HDR, MPO и «живые фото» сжимать с сохранением приложенного** (сейчас пропускаются, на папке
  владельца — 37 из 107 снимков S24 Ultra): пересжать основной кадр, а карту яркости / видео приложить как
  есть, пересчитав смещения в MPF и XMP (Container:Item). Проверять на телефоне и в Google Фото, что HDR живой.
- Продолжить подготовку с места остановки (сейчас «Подготовить» начинает заново).
- Собранную программу запустить на чистой Windows без VC++ Redistributable: `jpegtran` и `oxipng` берут
  `VCRUNTIME140.dll` из `_internal` (через PATH при запуске) — проверено только на машине разработки.
