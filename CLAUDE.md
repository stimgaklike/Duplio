# Duplio — правила проекта для Claude

Программа для Windows: поиск точных дубликатов файлов и удаление лишних копий в Корзину; сжатие фото
и видео (строго без потерь / без видимых потерь). Владелец — stimgaklike (общение по-русски, на «ты»). Репозиторий публичный:
https://github.com/stimgaklike/Duplio. План — `ROADMAP.md`, история — `CHANGELOG.md`.

## Как устроено

| Файл | Что внутри |
|---|---|
| `dupcore.py` | логика без окна: обход папок, группы по размеру → края (2×64 КБ) → BLAKE2b целиком; группы отдаются сразу (`on_group`), самые выгодные первыми; уровни нагрузки `LOAD_LEVELS`; `check_before_delete`; `to_recycle_bin` (SHFileOperationW); `has_recycle_bin` |
| `app.py` | главное окно, своя шапка `Tabs` (знак + QTabBar + QStackedWidget), трей, окно «в трей или закрыть», обновления (`UpdateDialog`, полоса-баннер), один экземпляр (QLocalServer), мьютекс `DuplioAppMutex` для установщика |
| `dups_page.py` | вкладка «Дубликаты»: поток поиска → сигналы `Bridge`, список (QTreeWidget) с пакетным добавлением `_flush` раз в 400 мс, отметки `marked`, сравнение (`FileCard`), быстрый просмотр (`QuickLook`), удаление в фоне |
| `compcore.py` | сжатие без окна: `prepare` (сжатые копии в `%LOCALAPPDATA%\Duplio\work`, фото в несколько потоков, видео по одному), `prepare_one`, `same_pixels` (байт в байт, 16 бит не округляются, альфа без предумножения), `ssim` (блоки 8×8, среднее и худший 1 %), `with_meta` (служебные блоки JPEG оригинала байт в байт), `replace` (копия рядом → сверка → оригинал в Корзину пачками → имя и даты), `set_times` |
| `compress_page.py` | вкладка «Сжатие»: режим, подготовка в потоке → `Bridge`, список «было → стало», превью (`Previews`: фото — QImageReader, видео — кадр ffmpeg в один момент у обоих), `CompareDialog`/`PairView` (100–400 %, обе половины вместе, за край не утащить), замена |
| `settings_page.py` | «Настройки» |
| `third_party\` (не в git) | jpegtran, oxipng, ffmpeg — `python tools/fetch_tools.py` (версии и SHA-256 закреплены; качает из своего релиза `deps`, потом у авторов); в сборку кладёт `prune_build.py`. Новая версия программы: файл — в релиз `deps` (`gh release upload deps …`), размер и SHA-256 — в `fetch_tools.py` |
| `thumbs.py` | превью: фото — QImageReader в QThreadPool; видео — кадр через QMediaPlayer+QVideoSink (без ffmpeg) |
| `updater.py` | GitHub Releases API → `Update`; скачивание с проверкой размера и SHA-256 (`digest` из API); тихая установка |
| `i18n.py` | `tr("русский шаблон {x}", x=…)`; английский — словарь `EN`; `plural`, `num`, `decimal` |
| `logs.py` | журнал `%LOCALAPPDATA%\Duplio\logs`, до 3 МБ, перехват ошибок (главный поток, потоки, Qt) |
| `settings.py` | `%APPDATA%\Duplio\settings.json`, `sanitize` — неверные значения → по умолчанию |
| `theme.py`, `icons/` | QSS светлой/тёмной темы, значки; `tools/make_brand.py` делает значки из `branding/src` |
| `installer.iss`, `build.bat`, `prune_build.py` | установщик Inno Setup (для текущего пользователя, без UAC), сборка PyInstaller папкой |
| `.github/workflows/` | `tests.yml` — тесты на push; `release.yml` — по метке `vX.Y.Z` тесты → сборка → релиз |

## Команды

```
python app.py                                   # запуск из исходников
python tools/fetch_tools.py                     # программы для сжатия (нужны тестам и сборке)
python -X utf8 -m unittest discover -s tests    # логика, сжатие, обновления, журнал, настройки
python -X utf8 tests/e2e_app.py <папка> dark    # окно целиком + снимки (light — светлая тема)
python -X utf8 tests/e2e_compress.py <папка> dark  # «Сжатие» целиком: оба режима, крупно, замена, мин. окно
python -X utf8 tests/e2e_english.py <папка>     # в английском интерфейсе нет ни одной русской строки
python tests/bench_resize.py                    # плавность (цель < 16 мс на шаг)
python tests/bench_scan_lag.py <папка>          # отзывчивость окна во время поиска
cmd /c "%CD%\build.bat"                         # программа + установщик в dist\ (из папки проекта, по полному пути)
```

## Правила работы

- **Данные пользователя — святое.** Удаление только через `check_before_delete` + повторная проверка после
  подтверждения; одна копия в группе остаётся всегда; на дисках без Корзины — явное «навсегда».
- **Каждый новый тест — проверить поломкой** (скилл владельца `testing:break-to-verify`): убрать правило,
  увидеть красный на своём утверждении, вернуть. Поломку применять скриптом из файла с `assert count == 1`
  (через `python -c` с экранированием она молча не ложится). Данные в тестах — настоящие (реальные mtime).
- **Экран мерить, а не смотреть** (`testing:measure-not-eyeball`): цвета строк, рамки, ширина текста,
  жирность — по пикселям `widget.grab()`; плюс снимок глазами.
- **Новая строка интерфейса → `tr()` и перевод в `i18n.EN`**, иначе `e2e_english.py` покраснеет.
  Одиночный `&` на кнопке Qt съедает — писать «and».
- **Не сканировать весь профиль пользователя** для замеров: там `CrossDevice` (телефон) и OneDrive —
  чтение заглушек скачивает файлы. Мерить на названных владельцу папках.
- Commit / push / метка выпуска — только после явного «да» владельца; перед отправкой показать список.
  Подпись коммитов в этом репозитории — `284795322+stimgaklike@users.noreply.github.com` (настроено локально).
- Находки, полезные другим проектам, — одной записью в `INBOX.md` репозитория скиллов владельца (правила — в его AGENTS.md).

## Грабли, на которые уже наступили

- **Шрифты Qt:** «Segoe UI Variable» даёт дорисованный жирный (зубцы), а Semibold 600 у «Segoe UI»
  рисуется обычным. Только «Segoe UI» + 700. Жирность в pseudo-state (`:checked { font-weight }`) не входит
  в размер виджета → текст обрезается.
- **QTreeWidget со стилем `::item`** не рисует `BackgroundRole` — фон строк рисует делегат `RowTint`.
- **Заполнение дерева по одной строке квадратично** (`setFirstColumnSpanned`, `setExpanded`): только пачкой.
- **QTabWidget с угловым виджетом** рисует лишнюю рамку — поэтому своя шапка `Tabs`.
- **Ширина ручки QSplitter** стилем не задаётся — `setHandleWidth`.
- **Наведение (`:hover`) в `grab()` не видно** — его заметность проверяется по цветам темы, нажатие — по пикселям (`setDown`).
- **Кадр видео:** первые кадры приходят до перемотки — ждать `startTime ≥ цели`; тёмный кадр — повтор ближе к середине.
- **Windows PowerShell 5** читает UTF-8 без BOM как ANSI: `.ps1`/`.iss` с русским — с BOM; `version.py` — только ASCII.
- **`Start-Process -Wait`** ждёт и запущенную установщиком программу — не использовать для проверки тихой установки.
- **Даты до 1970** — `datetime.fromtimestamp` падает на Windows: `fmt_date` безопасна.
- **Связки (junction) и точки монтирования** — `os.walk` по ним ходит; `dupcore._is_link` отсекает.
- **PyInstaller и `--add-data` с .exe:** он разбирает `ffmpeg.exe` и кладёт все его DLL ещё раз в корень
  `_internal` (+160 МБ). Поэтому `third_party` копирует `prune_build.py` после сборки.
- **Окно минимального размера:** QLabel с переносом и карточки получают высоту «на глаз», а если сумма
  минимумов вкладки больше окна, Qt сминает всё подряд (поле папки 16 px из 35). Мерить
  `page.minimumSizeHint().height() <= page.height()` и `layout_problems()` из `e2e_compress.py`.
- **Хвост JPEG после основной картинки** (`compcore.jpeg_tail`): Ultra HDR (карта яркости, `hdrgm` в XMP),
  MPO, «живые фото» и запись Samsung SEF лежат после EOI. jpegtran и пересжатие его выбрасывают, а проверка
  пикселей это не видит (основной кадр тот же) — так строгий режим чуть не испортил 37 HDR-снимков владельца.
  SEF (смещения от конца файла) переносится, картинка или видео в хвосте — файл пропускается.
- **jpegtran открывает файлы по ANSI-имени:** иероглифы и эмодзи не открываются нигде, на английской Windows
  (и на сервере GitHub, cp1252) — и кириллица. Поэтому файл подаётся ему на вход и забирается с выхода
  (`_run(src=, dst=)`), имя он не видит; тест `Names` — с «照片 фото 😀».
- **jpegtran возвращает 2 на предупреждениях** («лишние байты» — частое у камер): это не ошибка, файл собран;
  совпадение пикселей проверяется после.
- **SSIM и мелкое зерно:** на полном размере пропажу шумового зерна SSIM считает сильной потерей (снимки
  S24 Ultra при качестве 85 — медиана 0,959), хотя глазом почти не видно; поэтому фото сравниваются на кадре,
  уменьшенном вдвое. Пороги — только по настоящим снимкам (`compcore.PHOTO_SSIM_*`, там же числа калибровки).
- **В GitHub Actions вывод Python — в cp1252:** русский `print` роняет скрипт. Скрипты сборки делают
  `sys.stdout.reconfigure(encoding="utf-8")`; проверка — `PYTHONIOENCODING=cp1252 python скрипт | cat`.
- **Bash здесь съедает `\\` даже в `<<'EOF'`:** правки с обратной косой — через Write файла-скрипта или Edit.
  Так в `installer.iss` путь к каналу стал `'\.\pipe\…'` вместо `'\\.\pipe\…'` — установщик молча не мог
  попросить программу закрыться; теперь это сверяет `tests/test_installer.py` (путь, текст просьбы, мьютекс, BOM).
