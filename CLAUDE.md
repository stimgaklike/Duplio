# Duplio — правила проекта для Claude

Программа для Windows: поиск точных дубликатов файлов и удаление лишних копий в Корзину; сжатие фото
и видео (строго без потерь / без видимых потерь); «Метаданные» — убрать из фото и видео геометку, камеру,
время, автора без пересжатия. Владелец — stimgaklike (общение по-русски, на «ты»). Репозиторий публичный:
https://github.com/stimgaklike/Duplio. План — `ROADMAP.md`, история — `CHANGELOG.md`.

## Как устроено

| Файл | Что внутри |
|---|---|
| `dupcore.py` | логика без окна: обход папок, группы по размеру → края (2×64 КБ) → BLAKE2b целиком; группы отдаются сразу (`on_group`), самые выгодные первыми; уровни нагрузки `LOAD_LEVELS`; `check_before_delete`; `to_recycle_bin` (SHFileOperationW, пачки `step_for` ≈ 1/40 — счётчик «N из M» идёт плавно); `has_recycle_bin` |
| `app.py` | главное окно, своя шапка `Tabs` (знак + QTabBar + QStackedWidget), трей, окно «в трей или закрыть» (`busy_note` — что пропадёт при выходе), обновления (`UpdateDialog`, полоса-баннер), один экземпляр (QLocalServer `INSTANCE_KEY`; от установщика по нему же приходит `QUIT_REQUEST`), мьютекс `DuplioAppMutex`, перетаскивание на окно (`drop_plan` → подсказка `drop_hint` → `use_drop` / `use_folder` / `use_files`) |
| `dups_page.py` | вкладка «Дубликаты»: поток поиска → сигналы `Bridge`, список (QTreeWidget) с пакетным добавлением `_flush` раз в 400 мс, отметки `marked`, сравнение (`FileCard`, `clear_cards`), быстрый просмотр (`QuickLook`), удаление в фоне, `use_drop` |
| `compcore.py` | сжатие без окна: `prepare` (папка или список перетащенного — `gather`; сжатые копии в `%LOCALAPPDATA%\Duplio\work`, фото в несколько потоков, видео по одному), `prepare_one`, `same_pixels` (байт в байт, 16 бит не округляются, альфа без предумножения), `ssim` (блоки 8×8, среднее и худший 1 %; фото — на кадре вдвое, `photo_check`), видео — лестница `VIDEO_CRFS` с проверкой `video_vmaf` и сверкой времени кадров `same_timing`, `with_meta` (служебные блоки JPEG оригинала байт в байт), `jpeg_tail` (данные после картинки: запись Samsung переносится, HDR-карта / видео — файл пропускается), `replace` (копия рядом → сверка → оригинал в Корзину пачками → имя и даты), `set_times` |
| `compress_page.py` | вкладка «Сжатие»: режим, подготовка в потоке → `Bridge`, список «было → стало», превью (`Previews`: фото — QImageReader, видео — кадр ffmpeg в один момент у обоих), `CompareDialog`/`PairView` (100–400 %, обе половины вместе, за край не утащить), замена; `use_files` — сжать только перетащенное |
| `metacore.py` | метаданные без окна: `read` → `Item.fields` (`Field`: группа из `GROUPS`, имя, значение, `where` — приложенная картинка / видео, `locked` — почему не убрать); `clean_one` — копия без выбранных групп в `%LOCALAPPDATA%\Duplio\meta`, потом читается заново и сверяется (поля, картинка байт в байт, у видео — всё вне служебных блоков); `scan`, `clean`, `save_copies` (копии в папку, имя занято — «(2)»). JPEG: `Tiff.strip` — EXIF на месте (запись вынута из таблицы, данные затёрты нулями) или компактно, если нет `OFFSET_TAGS` и превью; XMP — `_xmp` (ElementTree; `XMP_NEEDED` не трогаются; `size=` — подгонка пробелами-заполнителем); IPTC — `_ps`; хвост — `_jpeg_tail` (приложенное по MPF и `_patch_mpf`, запись Samsung `_sef`). PNG — `_png`. MP4/MOV — `_Mp4`: размер файла не меняется (блоки → `free` с нулями, время в заголовках → 0, ключи `mdta` пересобираются и добиваются `free`) |
| `meta_page.py` | вкладка «Метаданные»: наборы «Всё» / «Только место» / «Свой набор» и галочки групп со счётчиком файлов; «Результат» — замена оригиналов или копии в папку; проверка и очистка в потоке; список «что уберётся» («не всё» — жёлтым); справа превью (прячется, если панель ниже `PIC_ROOM`) и таблица полей «уберётся / останется / не убрать»; `finish_before_exit` — начатую замену при выходе не обрывает |
| `settings_page.py` | «Настройки» |
| `third_party\` (не в git) | jpegtran, oxipng, ffmpeg — `python tools/fetch_tools.py` (версии и SHA-256 закреплены; качает из своего релиза `deps`, потом у авторов); в сборку кладёт `prune_build.py`. Новая версия программы: файл — в релиз `deps` (`gh release upload deps …`), размер и SHA-256 — в `fetch_tools.py` |
| `thumbs.py` | превью: фото — QImageReader в QThreadPool; видео — кадр через QMediaPlayer+QVideoSink (без ffmpeg) |
| `updater.py` | GitHub Releases API → `Update`; скачивание с проверкой размера и SHA-256 (`digest` из API); тихая установка |
| `i18n.py` | `tr("русский шаблон {x}", x=…)`; английский — словарь `EN`; `plural`, `num`, `decimal` |
| `logs.py` | журнал `%LOCALAPPDATA%\Duplio\logs`, до 3 МБ, перехват ошибок (главный поток, потоки, Qt) |
| `settings.py` | `%APPDATA%\Duplio\settings.json`, `sanitize` — неверные значения → по умолчанию |
| `theme.py`, `icons/` | QSS светлой/тёмной темы, значки; `tools/make_brand.py` делает значки из `branding/src` |
| `installer.iss`, `build.bat`, `prune_build.py` | установщик Inno Setup (для текущего пользователя, без UAC; открытый Duplio закрывает сам — пишет `duplio:quit` в его канал; при обновлении — «Обновление Duplio», «Обновить»; из программы `/UPDATE=1` — тихо ждёт её закрытия), сборка PyInstaller папкой |
| `.github/workflows/` | `tests.yml` — тесты на push; `release.yml` — по метке `vX.Y.Z` тесты → сборка → релиз; упавшие тесты — аннотациями (`tests/ci_annotate.py`), их видно без входа |
| `tests/` | `test_*.py` — unittest (в CI); `test_installer.py` — установщик и программа говорят одно (канал, текст, мьютекс, BOM); `test_i18n.py` — у каждого `tr("…")`, `Skip("…")` и названия из таблиц есть перевод, ключи не задвоены; `test_metacore.py` — снимки «как с телефона» собираются сами (MakerNote со смещением, превью, Ultra HDR с MPF, SEF, «живое фото»), проверка чужими глазами (Pillow, ffprobe); `e2e_*.py` — окно целиком на экране (не в CI) |

## Сборка для владельца и выпуск

- **Пробная сборка** — номер `X.Y.99` (после 1.1.0 — `1.1.99`), чтобы настоящий выпуск пришёл обновлением:
  `version.py` меняется только на время `build.bat` и возвращается байт в байт (не коммитится). Установщик —
  `dist\Duplio-Setup-X.Y.99.exe`, владелец ставит его поверх; старый пробный из `dist` удалять.
- **Выпуск** — после «да» владельца: CHANGELOG «Не выпущено» → «X.Y.Z — дата», ROADMAP «Сделано», коммит,
  `git tag vX.Y.Z && git push origin vX.Y.Z`. GitHub собирает и публикует сам (≈ 3 мин). Потом проверить
  `updater.check()` и заменить автоматический текст релиза (там только ссылка на коммиты, а его показывает окно
  обновления) человеческим: `gh release edit vX.Y.Z --notes-file …` (Markdown, по-русски + коротко по-английски).
- **`gh`** вошёл как `stimgaklike`; в Git Bash его нет в PATH — звать по полному пути (выше). Только чтение;
  отправка и метки — после «да».
- Релиз `deps` (предварительный, не «последний») — копии jpegtran / oxipng / FFmpeg для `fetch_tools.py`.

## Правила работы

- **Данные пользователя — святое.** Удаление только через `check_before_delete` + повторная проверка после
  подтверждения; одна копия в группе остаётся всегда; на дисках без Корзины — явное «навсегда».
- **Каждый новый тест — проверить поломкой** (скилл владельца `testing:break-to-verify`): убрать правило,
  увидеть красный на своём утверждении, вернуть. Поломку применять скриптом из файла с `assert count == 1`
  (через `python -c` с экранированием она молча не ложится). Данные в тестах — настоящие (реальные mtime).
- **Экран мерить, а не смотреть** (`testing:measure-not-eyeball`): цвета строк, рамки, ширина текста,
  жирность — по пикселям `widget.grab()`; плюс снимок глазами.
- **Новая строка интерфейса → `tr()` и перевод в `i18n.EN`**, иначе `e2e_english.py` покраснеет.
  Одиночный `&` на кнопке Qt съедает — писать «and».
- **Не сканировать весь профиль пользователя** для замеров: там `CrossDevice` (телефон) и OneDrive —
  чтение заглушек скачивает файлы. Мерить на названных владельцу папках.
- Commit / push / метка выпуска — только после явного «да» владельца; перед отправкой показать список.
  Подпись коммитов в этом репозитории — `284795322+stimgaklike@users.noreply.github.com` (настроено локально).
- Находки, полезные другим проектам, — одной записью в `INBOX.md` репозитория скиллов владельца (правила — в его AGENTS.md).

## Грабли, на которые уже наступили

- **Шрифты Qt:** «Segoe UI Variable» даёт дорисованный жирный (зубцы), а Semibold 600 у «Segoe UI»
  рисуется обычным. Только «Segoe UI» + 700. Жирность в pseudo-state (`:checked { font-weight }`) не входит
  в размер виджета → текст обрезается.
- **QTreeWidget со стилем `::item`** не рисует `BackgroundRole` — фон строк рисует делегат `RowTint`.
- **Заполнение дерева по одной строке квадратично** (`setFirstColumnSpanned`, `setExpanded`): только пачкой.
- **QTabWidget с угловым виджетом** рисует лишнюю рамку — поэтому своя шапка `Tabs`.
- **Ширина ручки QSplitter** стилем не задаётся — `setHandleWidth`.
- **Наведение (`:hover`) в `grab()` не видно** — его заметность проверяется по цветам темы, нажатие — по пикселям (`setDown`).
- **Кадр видео:** первые кадры приходят до перемотки — ждать `startTime ≥ цели`; тёмный кадр — повтор ближе к середине.
- **Windows PowerShell 5** читает UTF-8 без BOM как ANSI: `.ps1`/`.iss` с русским — с BOM; `version.py` — только ASCII.
- **`Start-Process -Wait`** ждёт и запущенную установщиком программу — не использовать для проверки тихой установки.
- **Даты до 1970** — `datetime.fromtimestamp` падает на Windows: `fmt_date` безопасна.
- **Связки (junction) и точки монтирования** — `os.walk` по ним ходит; `dupcore._is_link` отсекает.
- **PyInstaller и `--add-data` с .exe:** он разбирает `ffmpeg.exe` и кладёт все его DLL ещё раз в корень
  `_internal` (+160 МБ). Поэтому `third_party` копирует `prune_build.py` после сборки.
- **Окно минимального размера:** QLabel с переносом и карточки получают высоту «на глаз», а если сумма
  минимумов вкладки больше окна, Qt сминает всё подряд (поле папки 16 px из 35). Мерить
  `page.minimumSizeHint().height() <= page.height()` и `layout_problems()` из `e2e_compress.py`.
- **Хвост JPEG после основной картинки** (`compcore.jpeg_tail`): Ultra HDR (карта яркости, `hdrgm` в XMP),
  MPO, «живые фото» и запись Samsung SEF лежат после EOI. jpegtran и пересжатие его выбрасывают, а проверка
  пикселей это не видит (основной кадр тот же) — так строгий режим чуть не испортил 37 HDR-снимков владельца.
  SEF (смещения от конца файла) переносится, картинка или видео в хвосте — файл пропускается.
- **jpegtran открывает файлы по ANSI-имени:** иероглифы и эмодзи не открываются нигде, на английской Windows
  (и на сервере GitHub, cp1252) — и кириллица. Поэтому файл подаётся ему на вход и забирается с выхода
  (`_run(src=, dst=)`), имя он не видит; тест `Names` — с «照片 фото 😀».
- **jpegtran возвращает 2 на предупреждениях** («лишние байты» — частое у камер): это не ошибка, файл собран;
  совпадение пикселей проверяется после.
- **SSIM и мелкое зерно:** на полном размере пропажу шумового зерна SSIM считает сильной потерей (снимки
  S24 Ultra при качестве 85 — медиана 0,959), хотя глазом почти не видно; поэтому фото сравниваются на кадре,
  уменьшенном вдвое. Пороги — только по настоящим снимкам (`compcore.PHOTO_SSIM_*`, там же числа калибровки).
- **В GitHub Actions вывод Python — в cp1252:** русский `print` роняет скрипт. Скрипты сборки делают
  `sys.stdout.reconfigure(encoding="utf-8")`; проверка — `PYTHONIOENCODING=cp1252 python скрипт | cat`.
- **Сравнение после удаления:** `current_group = None`, а потом `show_group(None)` смены не видит и оставляет
  карточки удалённых файлов — сбрасывать через `clear_cards()`.
- **Тесты удаления и замены кладут свои файлы в настоящую Корзину** (так проверяется именно Корзина). Сам
  Корзину не чистить: это удаление навсегда — решение владельца. Несуществующие пути (тест счётчика) туда не попадают.
- **Временные папки e2e** — `atexit.register(shutil.rmtree, …)` сразу после `mkdtemp`: иначе остаются при обрыве.
- **Bash здесь съедает `\\` даже в `<<'EOF'`:** правки с обратной косой — через Write файла-скрипта или Edit.
  Так в `installer.iss` путь к каналу стал `'\.\pipe\…'` вместо `'\\.\pipe\…'` — установщик молча не мог
  попросить программу закрыться; теперь это сверяет `tests/test_installer.py` (путь, текст просьбы, мьютекс, BOM).
- **Переменная частота кадров у телефонов:** ночью Galaxy пропускает кадры (шаг 1/60…1/10 с, время не на сетке).
  Без `-fps_mode passthrough -enc_time_base demux` SVT-AV1 кладёт кадры на ровную сетку — движение и звук
  съезжают, а покадровое сравнение сравнивает не те кадры (ночной ролик: SSIM 0,930 вместо 0,982).
  Сверка — `compcore.same_timing` (по пакетам, 0,3 с на ролик). Тестовый ролик должен быть *не на сетке*
  (`settb=1/90000`, `-enc_time_base 1/90000`), иначе поломка не краснеет.
- **SSIM для видео почти слеп:** от CRF 24 до 36 средний SSIM 0,985 → 0,975, а VMAF 95 → 88 и глазом видно.
  Видео проверяется VMAF; libvmaf пишет журнал по ANSI-имени — имя латиницей, папка через `cwd`.
- **Кусок видео, вырезанный копированием (`-ss … -c copy`),** начинается с ключевого кадра раньше нужного —
  при замерах кадры съезжают (VMAF 21 вместо 88). Для калибровки — точная перемотка с распаковкой и для
  сжатия, и для эталона; программа сравнивает целые файлы с начала.
- **`sed -i` в Git Bash переводит CRLF в LF во всём файле** — diff становится «весь файл». Править — Edit или
  Python с `newline=""`; после — проверить, что концы строк прежние.
- **EXIF нельзя просто пересобрать:** запись производителя (MakerNote) и превью (IFD1) держат смещения от
  начала TIFF — после пересборки они указывают мимо. Поэтому `Tiff.strip` правит на месте и пересобирает,
  только если таких частей не осталось (`OFFSET_TAGS`). Одна защита маскировала другую (превью само запрещало
  пересборку) — поломка защиты MakerNote не краснела, пока тест не убрал и превью.
- **Смещения MPF (Ultra HDR, MPO) — от самого блока MPF:** блоки между ним и концом основной картинки меняют
  размер — смещения пересчитать (`_patch_mpf`). Pillow Ultra HDR как MPO не открывает (видит `hdrgm`) —
  в тестах вторая картинка ищется по `im._getmp()` и `info["mpoffset"]`.
- **Запись Samsung (SEF) с картой глубины или видео внутри не трогаем** — у владельца 6 из 103 снимков; её поля
  показываются «не убрать». Устройство SEF подтверждено на 103 снимках S24 Ultra.
- **Побайтовый цикл Python по сжатым данным JPEG** — 0,9 с на снимок; поиск маркера регулярным выражением
  (`metacore._MARKER`) — в 40 раз быстрее (223 снимка: 15 с → 0,6 с).
- **QStackedWidget** берёт минимальную высоту у всех страниц, включая скрытую, — скрытый на ней виджет не
  освобождает место. Показ/скрытие самих виджетов работает.
- **«Виджет наверху» не значит «текст наверху»:** у растянутой надписи текст по умолчанию посередине, а её
  `y` — у края. Мерить первую строку точек с буквами (`first_ink_row` в `e2e_meta.py`); цвет текста — самый
  частый цвет точек букв (края сглажены в оттенки).
